# Dr. Soumya Nandan Mishra — Academic Website

A responsive multi-page academic website with a compact homepage and dedicated detail pages.

## Pages
- `index.html` — Short homepage with profile, announcement, recent updates, education, work experience, and awards.
- `research.html` — Research interests and selected projects.
- `publications.html` — Journal articles, conference papers, and book chapters.
- `teaching.html` — Courses, teaching experience, and student projects.
- `contact.html` — Contact details and academic links.

## Design
The website uses a clean, minimal academic layout inspired by the supplied Karnish Tapadar reference: restrained colours, serif headings, simple horizontal navigation, generous whitespace, and compact chronological lists.
